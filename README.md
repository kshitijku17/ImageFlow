# ImageFlow
ImageFlow is a professional desktop application for photographers to quickly review, select, organize, and manage large collections of images. It allows users to copy selected photos, delete or move unwanted images, zoom, filter, navigate through thumbnails, and use AI-powered natural-language image search.
