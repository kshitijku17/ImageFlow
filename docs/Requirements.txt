PROJECT - 1

Project - ImageFlow (Desktop Application)

1. Source Folder -> Destination Folder
   By pressing a button -> images move into selected folder.

   Integrate AI-powered image search using OpenCLIP.
   User finds queries like "sun", "beach".
   OpenCLIP finds the matching images from the source folder
   and gives it to user.

   Python -
   Tkinter / PySide6 - GUI / Desktop
   FastAPI - Backend / API server, connect GUI with backend.
   Pillow (PIL) - Image processing and display.
   OpenCLIP - AI-based image search using text.
   SQLite - Store search history/info.
   Uvicorn - Run FastAPI server.


2. GUI Architecture ->
   PySide6 Desktop application with thumbnail grid, full viewer, and AI assistant dialogs.
